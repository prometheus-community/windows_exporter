# Claude Code guidance

Read [`AGENTS.md`](AGENTS.md) for this repository's shared agent instructions,
development workflow, implementation rules and pull request requirements.
Follow [`CONTRIBUTING.md`](CONTRIBUTING.md) for all changes.

## Component guidance

Also read any `AGENTS.md` in the directories you work on. Scoped instructions
describe the conventions and pitfalls of those components.

## Maintaining guidance

When an authorized change establishes a useful implementation detail or debugging
technique, update the relevant `AGENTS.md`. Add scoped guidance when a component
needs more detail, and keep shared project rules in the root `AGENTS.md` so they
stay consistent across agents.
